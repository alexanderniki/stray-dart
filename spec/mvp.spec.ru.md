# Спецификация: MVP — Случайный выбор строки (`stray`)

## 1. Контекст и цели
Цель MVP-релиза утилиты `stray` — предоставить надежный, минималистичный CLI-инструмент, который считывает текстовый файл в кодировке UTF-8, случайным образом выбирает одну строку и выводит её в `stdout`.

---

## 2. Контракт и интерфейс CLI

### 2.1. Синтаксис вызова
```bash
stray [флаги] <путь-к-файлу>
```

### 2.2. Позиционные аргументы
- `<путь-к-файлу>` (Обязательный): путь к целевому текстовому файлу. Разрешен строго один позиционный аргумент.

### 2.3. Опции и флаги
- `-h`, `--help`: вывод справочной информации в `stdout` и завершение с кодом `0`.
- `-v`, `--version`: вывод версии утилиты в `stdout` и завершение с кодом `0`.
- `-t`, `--truncate <int>`: обрезка длинных текстовых строк после указанного количества символов с добавлением многоточия (`…`).
- `-w`, `--wrap <int>`: перенос строки путем вставки перевода строки после указанного количества символов.
- `--seed <int>` (Опциональный): фиксирует seed псевдослучайного генератора чисел для детерминированного выбора строки (в первую очередь для тестов и воспроизводимых CLI-скриптов).

### 2.4. Коды возврата (Exit Codes)
- `0`: Успешное выполнение (а также вызов `--help` или `--version`).
- `1`: Ошибка пользователя / входных данных (не указан путь к файлу, файл не найден, файл недоступен для чтения, файл пуст, неверный формат значения `--seed`, `--truncate`, `--wrap`, неизвестные флаги).
- `2`: Непредвиденная внутренняя ошибка выполнения.

### 2.5. Стандартные потоки вывода
- `stdout`:
  - Содержит исключительно выбранную строку (с опциональной обрезкой/переносом и завершающим переводом строки), либо справку/версию.
- `stderr`:
  - Содержит сообщения об ошибках с префиксом `Error: <сообщение>`.

## 3. Граничные случаи и требования

1. **Нормализация окончаний строк:** как Unix-переносы (`\n`), так и Windows-переносы (`\r\n`) должны быть удалены из выбранной строки перед форматированием.
2. **Завершающие переводы строк:** наличие или отсутствие завершающего перевода строки в конце файла не должно влиять на количество строк. Пустая строка, образованная финальным `\n`, не считается кандидатом на выбор.
3. **Пустые файлы:** файл нулевого размера (0 байт) либо состоящий исключительно из символов переноса строки (`\n`, `\r\n`) считается пустым. Должен возвращаться код завершения `1` с сообщением `Error: File is empty`.
4. **Файлы из одной строки:** если в файле ровно одна строка, она должна выбираться всегда, независимо от значения seed.
5. **Кодировка UTF-8:** многобайтовые символы (Unicode, эмодзи, кириллица, иероглифы) должны считываться и выводиться без искажений.
6. **Указание директории:** если переданный путь ведет к директории, а не файлу, возвращается код `1` с сообщением `Error: Path is a directory`.
7. **Несуществующий файл:** если файл не существует, возвращается код `1` с сообщением `Error: File not found: <path>`.
8. **Обрезка строк (`-t`, `--truncate <int>`):** если задан параметр, то при превышении указанного количества символов строка обрезается с добавлением символа «многоточие» (`…`). Если длина строки меньше или равна лимиту, строка не изменяется. Значение должно быть положительным целым числом (> 0).
9. **Перенос строк (`-w`, `--wrap <int>`):** если задан параметр, то строка переносится на новую строку каждые указанные количество символов. Значение должно быть положительным целым числом (> 0).
10. **Совместная работа переноса и обрезки строк:** параметры `-t` (`--truncate`) и `-w` (`--wrap`) могут быть применены одновременно по правилам:
    - **Случай 1 (`width < truncate`):** текст переносится на новую строку каждые `width` символов и обрезается с подстановкой `…`, когда суммарная длина исходного текста достигает `truncate`.
    - **Случай 2 (`width >= truncate`):** значение параметра `width` игнорируется, текст обрезается строго в соответствии со значением `truncate`.

## 4. Сценарии приемки (BDD)

### Сценарий 1: Успешный выбор и вывод случайной строки
- **Дано:** файл `quotes.txt` со строками:
  ```
  Строка 1
  Строка 2
  Строка 3
  ```
- **Когда:** пользователь выполняет `stray quotes.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит одну из строк файла `quotes.txt` с символом перевода строки
- **И:** `stderr` пуст

### Сценарий 2: Детерминированный выбор с флагом `--seed`
- **Дано:** файл `items.txt` со строками `A`, `B`, `C`, `D`, `E`
- **Когда:** пользователь выполняет `stray --seed 42 items.txt` несколько раз
- **Тогда:** код завершения равен `0` при каждом запуске
- **И:** `stdout` выводит одну и ту же строку при каждом запуске для seed `42`

### Сценарий 3: Не передан аргумент пути к файлу
- **Когда:** пользователь выполняет `stray` без аргументов
- **Тогда:** код завершения `1`
- **И:** `stderr` содержит `Error: Missing required file path`
- **И:** `stderr` выводит инструкцию по использованию (usage)

### Сценарий 4: Файл не существует
- **Когда:** пользователь выполняет `stray non_existent.txt`
- **Тогда:** код завершения `1`
- **И:** `stderr` содержит `Error: File not found: non_existent.txt`

### Сценарий 5: Пустой файл
- **Дано:** пустой файл `empty.txt` (0 байт)
- **Когда:** пользователь выполняет `stray empty.txt`
- **Тогда:** код завершения `1`
- **И:** `stderr` содержит `Error: File is empty`

### Сценарий 6: Файл содержит только переводы строк
- **Дано:** файл `blanks.txt`, содержащий только `\n\n\n`
- **Когда:** пользователь выполняет `stray blanks.txt`
- **Тогда:** код завершения `1`
- **И:** `stderr` содержит `Error: File is empty`

### Сценарий 7: Поддержка кодировки UTF-8
- **Дано:** файл `unicode.txt` со строками:
  ```
  Привет, мир! 🚀
  你好，世界！
  ```
- **Когда:** пользователь выполняет `stray unicode.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит одну из строк в ненарушенной кодировке Unicode

### Сценарий 8: Опции справки и версии
- **Когда:** пользователь выполняет `stray --help` или `stray -h`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит справку по использованию и описание опций
- **Когда:** пользователь выполняет `stray --version` или `stray -v`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит номер версии утилиты

### Сценарий 9: Обрезка строки с флагом `-t` / `--truncate`
- **Дано:** файл `long.txt` со строкой:
  ```
  The quick brown fox jumps over the lazy dog
  ```
- **Когда:** пользователь выполняет `stray -t 15 long.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит `The quick brown…` с переводом строки

### Сценарий 10: Перенос строки с флагом `-w` / `--wrap`
- **Дано:** файл `wrap.txt` со строкой:
  ```
  ABCDEFGHIJ
  ```
- **Когда:** пользователь выполняет `stray -w 4 wrap.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит:
  ```
  ABCD
  EFGH
  IJ
  ```

### Сценарий 11: Совместная работа переноса и обрезки (`width < truncate`)
- **Дано:** файл `combined.txt` со строкой:
  ```
  ABCDEFGHIJKLMN
  ```
- **Когда:** пользователь выполняет `stray -w 4 -t 10 combined.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит:
  ```
  ABCD
  EFGH
  IJ…
  ```

### Сценарий 12: Совместная работа переноса и обрезки (`width >= truncate`)
- **Дано:** файл `combined.txt` со строкой:
  ```
  ABCDEFGHIJKLMN
  ```
- **Когда:** пользователь выполняет `stray -w 10 -t 5 combined.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит `ABCDE…` с переводом строки (`width` проигнорирован)
