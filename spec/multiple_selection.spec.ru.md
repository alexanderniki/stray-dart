# Спецификация: Множественная выборка строк (`-n, --count`)

## 1. Контекст и цели
В базовой версии (MVP) утилита всегда выбирает ровно одну случайную строку. Однако частые сценарии (получение выборки данных, показ 3 случайных советов, розыгрыши) требуют извлечения нескольких строк за один вызов.

Данная фича вводит параметр `-n, --count <int>`, позволяющий извлечь $N$ случайных строк из файла или потока.

---

## 2. Контракт и интерфейс CLI

### 2.1. Флаги и опции
- `-n, --count <int>`: Количество выбираемых случайных строк. Должно быть строго положительным целым числом ($n \ge 1$). Значение по умолчанию: `1`.

### 2.2. Логика выборки (без повторений)
- Строки выбираются **без повторений** (одна и та же строка файла не может быть выбрана дважды за один запуск).
- Если запрошенное количество $n$ превышает общее число доступных строк $M$ в файле ($n > M$), возвращаются все $M$ строк в случайном порядке.
- Каждая выбранная строка форматируется индивидуально в соответствии с активными флагами обрезки (`-t`) и переноса (`-w`).

### 2.3. Коды возврата (Exit Codes)
- `0`: Успешная выборка и вывод строк в `stdout`.
- `1`: Некорректное значение флага (не число, $\le 0$) или ошибка входных данных.

---

## 3. Сценарии приемки (BDD)

### Сценарий 1: Выбор нескольких уникальных строк
- **Дано:** файл `fruits.txt` с 5 строками: `Apple`, `Banana`, `Cherry`, `Date`, `Elderberry`
- **Когда:** пользователь выполняет `stray -n 3 fruits.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит ровно 3 различные строки из файла
- **И:** дубликаты строк в выводе отсутствуют

### Сценарий 2: Запрошенное количество больше числа строк в файле
- **Дано:** файл `two.txt` со строками `Line 1` и `Line 2`
- **Когда:** пользователь выполняет `stray -n 5 two.txt`
- **Тогда:** код завершения `0`
- **И:** `stdout` выводит обе строки в случайном порядке

### Сценарий 3: Некорректное значение счетчика
- **Когда:** пользователь выполняет `stray -n 0 fruits.txt` или `stray -n -3 fruits.txt`
- **Тогда:** код завершения `1`
- **И:** `stderr` содержит `Error: Invalid value for --count: must be a positive integer`

### Сценарий 4: Множественная выборка с форматированием
- **Дано:** файл с длинными строками
- **Когда:** пользователь выполняет `stray -n 2 -t 10 long.txt`
- **Тогда:** код завершения `0`
- **И:** каждая из выведенных строк обрезана до 10 символов с добавлением многоточия `…`
