# Спецификация: Поддержка стандартного потока ввода (`stdin`)

## 1. Контекст и цели
Для бесшовной интеграции утилиты `stray` в конвейеры командной строки (UNIX pipelines) необходима возможность передачи данных через стандартный поток ввода (`stdin`) без необходимости сохранения во временный файл на диске (например: `cat list.txt | stray -` или `curl -s https://example.com/quotes | stray -`).

---

## 2. Контракт и интерфейс CLI

### 2.1. Синтаксис вызова
```bash
# Явный дефис как обозначение stdin:
stray [флаги] -

# Неявное обнаружение конвейера (когда stdin подключен к pipe и путь к файлу не передан):
команда | stray [флаги]
```

### 2.2. Позиционные аргументы
- Если в качестве аргумента передан символ `-`, считывание данных выполняется из `stdin`.
- Если аргумент не передан, но поток `stdin` перенаправлен из пайпа (не является TTY-терминалом), утилита автоматически переключается на чтение из `stdin`.
- Если аргумент не передан и `stdin` является терминалом, возвращается ошибка `1` с подсказкой по использованию (usage).

### 2.3. Коды возврата (Exit Codes)
- `0`: Успешный выбор и вывод случайной строки из `stdin`.
- `1`: Ошибка ввода (поток `stdin` пуст, неверные флаги).
- `2`: Внутренняя ошибка (обрыв конвейера / I/O сбой).

---

## 3. Сценарии приемки (BDD)

### Сценарий 1: Явное указание stdin через дефис (`-`)
- **Дано:** поток строк `Alfa`, `Beta`, `Gamma`, переданный в `stdin`
- **Когда:** пользователь выполняет `stray -`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит одну из переданных строк

### Сценарий 2: Передача данных через конвейер с флагами форматирования
- **Дано:** длинная строка, поданная на вход через `echo`
- **Когда:** пользователь выполняет `echo "..." | stray -t 10 -`
- **Тогда:** код завершения `0`
- **И:** `stdout` содержит обрезанную строку с многоточием `…`

### Сценарий 3: Пустой стандартный поток ввода
- **Дано:** пустой поток (`echo -n ""`)
- **Когда:** пользователь выполняет `stray -`
- **Тогда:** код завершения `1`
- **И:** `stderr` содержит `Error: Standard input is empty`
